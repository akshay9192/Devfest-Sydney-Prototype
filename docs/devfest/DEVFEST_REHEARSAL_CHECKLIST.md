# DevFest rehearsal checklist

## Before talk

- [ ] Laptop charged; charger and display adapter packed.
- [ ] `DevFest_Sydney_2026.pptx` copied locally and opened offline.
- [ ] GitHub QR decoded and tested from a second device.
- [ ] Repository is public and accessible while signed out.
- [ ] Local PDF backup present if export succeeded.
- [ ] Presentation mode, aspect ratio, fonts, and projector readability tested.
- [ ] Full talk timed at or below 2:50, including slide changes.

## On stage

- [ ] Do not deploy to cloud or depend on venue Wi-Fi.
- [ ] Give the architecture-first talk; do not make the UI the centerpiece.
- [ ] Keep total delivery at or below 2:50.
- [ ] Leave the repository QR visible on the final slide.

## Backup

- [ ] PDF export available locally if created.
- [ ] Slide screenshots available under `docs/devfest/deck_work/origin_image/`.
- [ ] Local repository available for questions.
- [ ] Existing deterministic offline demo available only if needed.

## After talk

- [ ] Repository link ready to paste and share.
